# The designer's bookmarked sites

Sites the designer saved in their browser's "Web Design" folder during 2025 and 2026, visited
once on 2026-11-24 and tagged. Load this file at the research stage, or for a quick inspiration
request, and use it as the first place to look for references.

## How to use it

1. From the brief, pick the matching sector section and also scan other sections for the notes
   that match the wanted character (for example "serif headline", "full-bleed photo").
2. Shortlist a handful. **Open each one again** before citing it: sites change, and these notes
   describe only what was seen on the date above. The honesty rules in
   [research.md](research.md) apply in full.
3. Put the ones that still hold up on the reference board next to references found fresh. A
   bookmark is a candidate, not an automatic inclusion: the designer saved some for one detail,
   and some for reasons other than design.

## What the notes are and are not

- Each note describes the **first screen at desktop width (1440 × 900) only**. Inner pages,
  mobile layout, scroll and motion were not reviewed.
- "Type" is the font family the browser reported for the main heading and for body text. It is a
  lead for type research, not a verified licence or foundry name.
- **★** marks sites whose first screen showed a clear, distinctive idea. This is the agent's
  judgement, not the designer's ranking.
- Why the designer saved each site is not known. Ask when it matters.
